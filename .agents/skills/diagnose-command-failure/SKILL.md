# コマンド失敗の診断（Codex 用入口）

[Codex 向け案内](../../../CODEX.md) の参照順と読み替えを適用し、
[手順本体](../../../.agent/skills/diagnose_command_failure/SKILL.md) を実際に開いてから作業する。
手順内の相対リンク・補助ファイルは手順本体の場所を基準に解決する。

診断スクリプトは手順本体と同じディレクトリの `scripts/` を参照する。
保存する診断ログは `temp/` の作業フォルダに置く。
